# KAR-Decomp
Yet another Kirby Air Ride decomp, but using PPC

Compiles
```
Kirby Air Ride || NA
Game ID: GKYE01
Hash: 977533bb96e6a16e127946396489be1b4164ac42

Kirby's Air Ride || JP
Game ID: GKYJ01
Hash: e901b9912af1b622c1f6d16fab6efe6cf505f108

Kirby Air Ride || PAL
Game ID: GKYP01
Hash: 14e43ef2e3d971bbb6aae596a175ac485ff242a8

Korean/KOR version is ignored as it's just the NA version
```
WE DO NOT PROVIDE GAME ASSETS!!!!!!!!!!!!!!!!!

[PPC](https://github.com/Static-Recomp/PPC_Transcompiler) is a WIP static recompiler for Game Cube and Wii games. It uses DTK as a base and static anaylisis to convert the assembly into C/C++ and generate type info.

[DTK](https://github.com/encounter/decomp-toolkit) is a toolkit for working with Game Cube and Wii decomps. Thanks to [Encounter](https://github.com/encounter) and the [GC/Wii Discord](https://discord.gg/hKx3FJJgrV)

And most importainly, a very special thank you to [WowJinxy](https://github.com/wowjinxy). Who leads the [OG KAR Decomp](https://github.com/doldecomp/kar/tree/main). PPC would not have got it's inital development or sprung forward as quickly as it has without them :3.

# Project Structure

- configure.py || python script from the DTK Toolkit that splits and compiles the ROMs.
- ExtractedISOs || place your extracted ROM filesystems here.
- tools || a few tools used by DTK and PPC
- build || the build directory where objects will be dumped and final dols will be generated.
----------------------------------------------
- NA || handes all the code and config for the North American version of KAR.
- NA/SymbolMaps || all the symbol maps found or map for KAR over the years. Thanks Jinxy. Will be merged into one uber map and symbol list.
- NA/SymbolsNSplits || The symbols and splits of the ROM.
- NA/asm || The assembly code outputted by DTK and processed through PPC.
- NA/config || Config info used by DTK.
----------------------------------------------
- PAL || handes all the code and config for the PAL version of KAR.
- PAL/SymbolsNSplits || The symbols and splits of the ROM.
- PAL/asm || The assembly code outputted by DTK and processed through PPC.
- PAL/src || The C++ code ouputted by PPC generated by the ASM.
- PAL/config || Config info used by DTK.
----------------------------------------------
- JP || handes all the code and config for the JP version of KAR.
- JP/SymbolsNSplits || The symbols and splits of the ROM.
- JP/asm || The assembly code outputted by DTK and processed through PPC.
- JP/src || The C++ code ouputted by PPC generated by the ASM.
- JP/config || Config info used by DTK.

## Extracting the assets from your ISO

1. Grab a NA, JP, or PAL ISO of Kirby Air Ride. We can not provide one.

2. Extract it yourself using Dolphin or run the pyton script `ExtractROM.py`.

`python ExtractROM.py <path to your ISO>`
